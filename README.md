# Horizon High Context Topic Cards

A Discourse theme component taking the High Context Topic Cards Discourse created for the Horizon theme and turning them into an independent theme component so they can be used elsewhere. Right now, the high context topic cards are only usable on the Horizon theme so it must be taken out of the Horizon theme and converted into a theme component to be useable by other themes.

Hopefully not a fork we'll have to keep forever because Discourse will update one of their topic card components to match, or will pull it out of the Horizon theme to become a component of its own.
